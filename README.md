Rozwiązane notatniki z laboratoriów (Google Colab, GPU T4, TensorFlow/Keras 3, PyTorch).

| Lab | Temat | Plik |
|---|---|---|
| L1 | Środowisko, tensory i gradient od podstaw | `Lab01_Srodowisko_tensory_gradient_rozwiazanie.ipynb` |

## Jak uruchomić

1. Otwórz [Google Colab](https://colab.research.google.com) → **Plik → Prześlij notatnik** (albo **GitHub** i wklej adres tego repozytorium).
2. **Środowisko wykonawcze → Zmień typ środowiska wykonawczego → T4 GPU**.
3. **Środowisko wykonawcze → Uruchom wszystko**.

Bez GPU ustaw `SZYBKI_TRYB = True` w pierwszej komórce z kodem (mniej danych i epok).
